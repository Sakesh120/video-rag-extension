# Video RAG Extension 📺🤖

Video RAG Extension is a Chrome browser extension that allows users to seamlessly chat with an AI bot about the YouTube video they are currently watching. By leveraging Retrieval-Augmented Generation (RAG) on video transcripts, the bot can answer specific questions, summarize content, and pull key insights directly from the video.

## ✨ Features

- **Interactive AI Chat:** Ask questions and get instant answers about the YouTube video you are watching.
- **Context-Aware Responses:** Powered by RAG, the bot uses the video's actual transcript to provide accurate, grounded answers.
- **Seamless YouTube Integration:** Works directly on YouTube pages without needing to copy-paste links into a separate app.
- **Time-Saving Summaries:** Instantly understand long videos or tutorials without having to watch them entirely.
